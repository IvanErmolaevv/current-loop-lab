# Лаборатория токового контура

**[Открыть симуляцию в браузере](https://ivanermolaevv.github.io/current-loop-lab/)**

Интерактивная симуляция движения массивного замкнутого контура с током рядом с бесконечным прямым проводом. Нарисуйте контур, задайте токи и массу, затем проследите за его перемещением и вращением в течение выбранного времени. Гравитации нет, масса определяет инерцию.

Приложение работает в браузере, без сборки, установки npm-пакетов и сервера с вычислениями. Исходные файлы сайта находятся в `dist/`.

## Запуск

Понадобятся Python 3 и современный браузер. Из каталога репозитория выполните:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте [localhost:8080](http://localhost:8080). Все вычисления происходят на вашем устройстве.

1. Выберите готовый контур или нарисуйте собственный замкнутый контур рядом с проводом.
2. Установите ток в прямом проводе, ток в контуре, его массу и длительность опыта.
3. Запустите симуляцию. Меняйте направление тока, чтобы сравнивать движение; используйте паузу и сброс для повторения опыта.
4. Просматривайте рассчитанную траекторию временным ползунком и скачивайте её в CSV. Скорость воспроизведения меняет темп показа, а не физические законы.

В режиме рисования ставьте вершины щелчками и нажмите «Замкнуть» или проведите контур от руки с зажатой кнопкой. Контур должен быть без самопересечений, целиком справа или слева от провода. Колесо меняет масштаб, пробел и перетаскивание сдвигают вид. Положительное направление тока контура — против часовой стрелки, независимо от направления рисования.

## Физическая модель

Система находится в плоскости `xy`. Прямой провод неподвижен, бесконечен и расположен на `x = 0`; положительный ток `I₁` направлен вдоль `+y`. В плоскости рисунка поле имеет только компоненту `z`:

```text
Bz(x) = −μ₀ I₁ / (2πx),   x ≠ 0
μ₀ ≈ 4π × 10⁻⁷ Н/А²
```

Справа от провода при положительном `I₁` поле направлено в экран. Модуль поля убывает обратно пропорционально расстоянию до провода, как следует из [закона Ампера для бесконечного прямого провода, OpenStax / Rice University](https://openstax.org/books/university-physics-volume-2/pages/12-5-amperes-law).

Нарисованная линия представляет жёсткий плоский проволочный контур с равномерной линейной плотностью массы `λ = m/L`. Центр масс и момент инерции определяются по длине линии, а не по площади внутри неё:

```text
rCM = (1/L) ∮ r dl
J = (m/L) ∮ |r − rCM|² dl
```

На каждый элемент контура действует магнитная сила. Суммарные сила и момент силы вычисляются по всему контуру, с учётом неоднородности поля:

```text
dF = I₂ dℓ × B
F = ∮ dF
τz = ∮ [(r − rCM) × dF]z
m r̈CM = F
J θ̈ = τz
```

Основа расчёта — [сила на элемент проводника с током, OpenStax / Rice University](https://openstax.org/books/university-physics-volume-2/pages/11-4-magnetic-force-on-a-current-carrying-conductor). Каждый прямой участок контура интегрируется аналитически. Движение рассчитывается методом Рунге — Кутты 4-го порядка с подшагами не более 5 мс и дополнительным уменьшением шага вблизи провода.

Все расчёты используют СИ: расстояния — метры, время — секунды, масса — килограммы, ток — амперы, сила — ньютоны, поле — тесла, момент силы — Н·м. Если интерфейс показывает производные единицы, значения переводятся в СИ перед расчётом.

## Допущения и границы применимости

- Контур движется и вращается только в своей плоскости. Его форма и длина сохраняются; упругость и деформация не моделируются.
- Оба тока постоянны и поддерживаются идеальными внешними источниками. Электромагнитная индукция, сопротивление, нагрев, самоиндукция и собственные магнитные силы контура не учитываются.
- Прямой провод закреплён. Его обратное движение под действием контура не рассчитывается.
- Нет гравитации, трения, сопротивления среды и искусственного затухания.
- Формула идеального тонкого провода имеет особенность на `x = 0`. Исключённая область имеет радиус 2,5 см; при касании её поверхности расчёт останавливается. Удар и последующая деформация не моделируются; контур должен оставаться по одну сторону провода.
- Численное решение имеет погрешность. Особенно быстро она растёт при малом расстоянии до провода, больших токах и резких изменениях силы.

Это модель жёсткого контура с заданным током. Для пассивного проводящего кольца, в котором ток возникает из-за изменения магнитного потока, требуется другая модель с законом Фарадея и электрической цепью. Кинетическая энергия контура меняется за счёт взаимодействия с полем и источниками тока. Для постоянных заданных токов используемый эффективный потенциал `U = −I₂Φ` даёт сохраняющуюся величину `K + U`; её относительный дрейф отображается как погрешность энергии. Это не полная энергия электромагнитного поля и источников.

## Проверка физики

Проверки выполняются встроенным тестовым модулем Node.js:

```sh
node --test tests/physics.test.js
```

## Публикация в GitHub Pages

Исходный код находится в ветке `main`, готовые статические файлы — в ветке `gh-pages`. Сборка и npm-пакеты не требуются. Настройка основана на [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source → Deploy from a branch**, ветку `gh-pages` и каталог `/ (root)`. После успешного развёртывания фактическая ссылка появится в разделе Pages.

Для обновления сайта после изменения исходников:

```sh
node --test tests/physics.test.js
git add dist README.md tests package.json
git commit -m "Update simulation"
git push origin main
git subtree push --prefix dist origin gh-pages
```
